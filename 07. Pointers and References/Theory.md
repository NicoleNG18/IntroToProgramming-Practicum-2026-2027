# const и указатели – 4-те случая

Четем отдясно наляво: `const` **преди** `*` → константна е стойността; `const` **след** `*` → константен е указателят.

| Декларация | `*p = ...` (смяна на стойността) | `p = ...` (пренасочване) |
|---|---|---|
| `int* p` | ✅ | ✅ |
| `const int* p` / `int const* p` | ❌ | ✅ |
| `int* const p` | ✅ | ❌ |
| `const int* const p` | ❌ | ❌ |

```cpp
int a = 5, b = 10;
```

## 1. `int* p` – всичко може

```cpp
int* p = &a;
*p = 7;    // ✅ a става 7
p = &b;    // ✅ p вече сочи към b
```

## 2. `const int* p` / `int const* p` – стойността не може да се променя

```cpp
const int* p = &a;
*p = 7;    // ❌ грешка: стойността е константна (през p)
p = &b;    // ✅ може да сочи другаде
```

## 3. `int* const p` – указателят не може да се пренасочва

```cpp
int* const p = &a;   // трябва да се инициализира веднага
*p = 7;    // ✅ a става 7
p = &b;    // ❌ грешка: p е константен
```

## 4. `const int* const p` – нищо не може

```cpp
const int* const p = &a;
*p = 7;    // ❌
p = &b;    // ❌
```
