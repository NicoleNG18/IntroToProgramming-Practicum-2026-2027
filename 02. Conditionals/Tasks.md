### 🔹 Задача 1 — Еквивалентни ли са програмите?

```cpp
#include <iostream>

int main()
{
    int x;
    std::cin >> x;
    if (x % 2 == 0)
        std::cout << "even";
    else
        std::cout << "odd";
}
```

```cpp
#include <iostream>

int main()
{
    int x;
    std::cin >> x;
    switch (x % 2)
    {
        case 0: std::cout << "even"; break;
        case 1: std::cout << "odd"; break;
    }
}
```

### 🔹 Задача 2 — Какво ще отпечата следният код?

```cpp

{

    if (a > b)

        std::cout << "C";
    else
        std::cout << "D";
}
```

### 🔸 Задача 5 — Какво ще отпечата следният код?

```cpp
#include <iostream>

{
    int a = 0, b = 5;

    if (a != 0 && b / a > 1)

        std::cout << "B";
```

### 🟡 Задача 8 — Калкулатор с меню

Напишете програма, която отпечатва меню и според избора на потребителя изпълнява съответната операция върху две цели числа `a` и `b`.

```
1. Събиране
2. Изваждане
3. Умножение
4. Деление
5. Остатък при деление
Избор:
```

Въвеждат се изборът и двете числа. Изисквания:

- При деление и остатък, ако `b == 0`, изведете `Division by zero`.
- При невалиден избор изведете `Invalid option` (използвайте `default`).

<details>
<summary>📥 Вход / 📤 Изход</summary>

<br>

| Вход | Изход |
|:---|:---|
| `1`<br>`7 2` | `9` |
| `4`<br>`7 2` | `3.5` |
| `5`<br>`7 0` | `Division by zero` |
| `9`<br>`7 2` | `Invalid option` |

</details>

### 🟡 Задача 9 — Вид на триъгълник

Въведете три реални числа – страни на триъгълник. Ако не образуват триъгълник, изведете `Not a triangle`. В противен случай класифицирайте триъгълника:

- **по страни:** `Equilateral` (равностранен), `Isosceles` (равнобедрен) или `Scalene` (разностранен);
- **по ъгли:** `Right` (правоъгълен), `Acute` (остроъгълен) или `Obtuse` (тъпоъгълен).

> 💡 Подсказка: ако `c` е най-голямата страна, сравнете $a^2 + b^2$ с $c^2$.

> ⛔ ~~`std::max`~~ ⛔ ~~`std::sort`~~ ⛔ ~~`std::sqrt`~~ – най-голямата страна трябва да се намери само с условни конструкции.

<details>
<summary>📥 Вход / 📤 Изход</summary>

<br>

| Вход | Изход |
|:---|:---|
| `3 4 5` | `Scalene, Right` |
| `5 5 5` | `Equilateral, Acute` |
| `2 2 3` | `Isosceles, Obtuse` |
| `1 2 3` | `Not a triangle` |

</details>

### 🌟 Бонус 1 — Следващият ден

Въведете дата като три цели числа – ден, месец и година. Проверете дали датата е валидна (съобразете броя дни в месеца и високосните години). Ако е валидна, изведете датата на **следващия ден** във формат `DD.MM.YYYY`, в противен случай – `Invalid date`.

<summary>📥 Вход / 📤 Изход</summary>

|:---|:---|

| `28 2 2023` | `01.03.2023` |
| `31 12 2025` | `01.01.2026` |
| `31 4 2025` | `Invalid date` |

</details>
