<summary><h3>🔹 Задача 1 · <ins>Какво ще се изведе?</ins></h3></summary>

```cpp
#include <iostream>

int main()
{
    int x[5] = {2};
    std::cout << x[0] << " " << x[1];
}
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

`{2}` задава ***само първия*** елемент, а <ins>**останалите се нулират**</ins> по подразбиране.

```text
x = {2, 0, 0, 0, 0}
```

> ✅ **Изход:** `2 0`

</details>

</details>

<details>
<summary><h3>🔹 Задача 2 · <ins>Какво ще изведе програмата?</ins></h3></summary>

```cpp
#include <iostream>

int main()
{
    int a[5] = {1, 2, 3, 4};
    std::cout << a[2] << "\n";
    std::cout << a[0] + a[4] << "\n";
}
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

Зададени са само 4 стойности, затова `a[4]` е ***нулирано***:

```text
a = {1, 2, 3, 4, 0}
```

| Израз | Стойност |
| :---: | :------: |
| `a[2]` | **`3`** *(третият елемент)* |
| `a[0] + a[4]` | `1 + 0 =` **`1`** |

> ✅ **Изход:**
>
> ```text
> 3
> 1
> ```

</details>

</details>

<summary><h3>🔹 Задача 3 · <ins>Какво ще се изведе и как изглежда масивът във всеки момент?</ins></h3></summary>

```cpp
#include <iostream>

int main()
{
    int a[5] = {3, 1, 4, 1, 5};
    a[2] = a[0] + a[4];
    a[4] = a[1];
    std::cout << a[2] << " " << a[4];
}
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

| Стъпка | Масив |
| :----- | :---- |
| начало | `{3, 1, 4, 1, 5}` |
| `a[2] = a[0] + a[4]` → `3 + 5` | `{3, 1, `**`8`**`, 1, 5}` |
| `a[4] = a[1]` → `1` | `{3, 1, 8, 1, `**`1`**`}` |

> ✅ **Изход:** `8 1`

</details>

</details>

<details>
<summary><h3>🔹 Задача 4 · <ins>Валиден ли е следният код?</ins></h3></summary>

```cpp
int a[3] = {1, 2, 3};
int b[3];
b = a;
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

> ❌ **Не!** Масивите в C++ <ins>**не могат да се присвояват**</ins> един на друг с `=`. Ще се получи ***грешка при компилация***.

Копирането става ***елемент по елемент***:

```cpp
for (int i = 0; i < 3; i++)
    b[i] = a[i];
```

</details>

</details>

<summary><h3>🔸 Задача 5 · <ins>Какво ще изведе следният код?</ins></h3></summary>

```cpp
#include <iostream>

int f(int a)
{
    std::cout << "f()" << std::endl;
    return a;
}

int g(int a)
{
    std::cout << "g()" << std::endl;
    return a + 1;
}

int h(int a)
{
    std::cout << "h()" << std::endl;
    return a + 2;
}

int calc(int a)
{
    return f(g(h(a)));
}

int main()
{
    std::cout << calc(3);
}
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

> 🧅 Функциите се извикват <ins>**отвътре навън**</ins>.

| Извикване | Резултат |
| :-------- | :------: |
| `h(3)` | `3 + 2 =` **`5`** |
| `g(5)` | `5 + 1 =` **`6`** |
| `f(6)` | **`6`** |

> ✅ **Изход:**
>
> ```text
> h()
> g()
> f()
> 6
> ```

</details>

</details>

<details>
<summary><h3>🔸 Задача 6 · <ins>Има ли проблем в този код? Ако да, какъв и защо?</ins></h3></summary>

```cpp
#include <iostream>

int f(int a, int b)
{
    return a + b;
}

double f(int a, int b)
{
    return a + b;
}

int main()
{

}
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

> ❌ **Да, има проблем.** <ins>**Не може**</ins> да има две функции с ***еднакви параметри*** и ***различен тип на връщане***.

Компилаторът избира коя функция да извика ***само по параметрите***. Типът на резултата не е достатъчен, за да ги различи.

> ⛔ Резултат: ***грешка при компилация***.

</details>

</details>

<summary><h3>🔸 Задача 7 · <ins>Какво ще изведе следният код?</ins></h3></summary>

```cpp
#include <iostream>

bool f(int a)
{
    std::cout << "f()" << std::endl;
    return a;
}

bool g(int b)
{
    std::cout << "g()" << std::endl;
    return b % 2 == 0;
}

bool h(int a, int b)
{
    std::cout << "h()" << std::endl;
    return a && b;
}

void test()
{
    std::cout << (f(0) || g(4) || h(0, 2)) << std::endl;
}

int main()
{
    test();
}
```

<details>
<summary><b>💡 Обяснение</b></summary>

<br>

| Извикване | Връща | Продължава ли? |
| :-------- | :---: | :------------- |
| `f(0)` | `false` | ✅ да, към `g(4)` |
| `g(4)` | `true` | ⛔ не, изразът вече е `true` |
| `h(0, 2)` | — | <ins>**не се извиква**</ins> |

> ⚡ ***Short-circuit:*** при `||` щом някой операнд е `true`, останалите ***не се изчисляват***.

> ✅ **Изход:**
>
> ```text
> f()
> g()
> 1
> ```

</details>

В равнината има `n` точки. Координатите им са дадени в два масива, `x[]` и `y[]`, с размер `n` (***1 ≤ n ≤ 128***).

> 📐 **Математическа насока:** разстоянието между $(x_1, y_1)$ и $(x_2, y_2)$ е


**📤 Изход:**

```text
4
```

> 💡 *Защо:* най-отдалечени са `(0, 0)` и `(3, 1)`: `|0 - 3| + |0 - 1| = 4`. Останалите двойки дават `3`.

<summary><h3>🟡 Задача 7 · Умножение на полиноми</h3></summary>

Полиномът се представя с масив, в който ***индексът*** е степента на `x`, а ***стойността*** е коефициентът пред нея.

> 💡 *Пример:* `{2, -3, 5}` означава $2 - 3x + 5x^2$

Напишете функция, която приема два полинома с размери `n` (***1 ≤ n ≤ 128***) и `m` (***1 ≤ m ≤ 128***) и записва ***произведението им*** в <ins>**трети масив**</ins> с размер `n + m - 1`.

> 📐 **Математическа насока:** коефициентът пред $x^k$ в резултата е сумата от всички произведения, чиито индекси се събират до $k$:
>
> $$C[k] = \sum_{i + j = k} A[i] \cdot B[j]$$
>
> т.е. за всяко `i` и `j`: `C[i + j] += A[i] * B[j]`

<details>
<summary><b>📥 Вход / 📤 Изход</b></summary>

<br>

**📥 Вход:**

```text
A = [1, 2]    // 1 + 2x
B = [3, 1]    // 3 + x
```

**📤 Изход:**

```text
[3, 7, 2]     // 3 + 7x + 2x²
```

</details>

<summary><h3>🌟 Бонус 1 · Компресиране на масив</h3></summary>

Въведете `n` (***1 ≤ n ≤ 128***) и масив от `n` ***цифри***. Напишете функция, която връща ***компресираната версия*** на масива ***като число***.

> 💡 *Пример:* `3` се повтаря 6 пъти → `36`, `4` 2 пъти → `42`, `5` 1 път → `51` и т.н.

> ⚠️ Резултатът бързо надхвърля `int`, затова използвайте <ins>**`long long`**</ins>.
