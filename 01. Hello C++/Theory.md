## 🔤 Азбука на езика C++

> 💬 *Както обикновеният език си има азбука, така и C++ има <ins>специални символи</ins>, <ins>запазени думи</ins> и <ins>конструкции</ins>, с които се изразяваме.*

### ✔️ Позволени символи в една програма

| Вид | Символи |
| :-- | :------ |
| 🔠 **Латински букви** | `a`–`z`, `A`–`Z` |
| 🔢 **Цифри** | `0`–`9` |
| ✳️ **Специални символи** | `+` `-` `*` `/` `=` `()` `[]` `{}` `\|` `&` `!` `<` `>` `#` `$` `^` `%` `~` `_` `.` `,` `:` `;` `'` `"` |
| ␣ **Разделители** | интервал, табулация (`\t`), нов ред (`\n`) |

### 🔡 Case Sensitive

> ⚠️ C++ ***различава главни от малки букви***. Има значение дали думата съдържа главни букви или не.

```text
portal  ≠  Portal
GLaDOS  ≠  glados
jacob   ≠  jaCob
```

## 🧱 Основни елементи на една програма

### 🏷️ Идентификатори

С тях ***именуваме*** променливи, константи, типове данни и други неща, създадени от програмиста.

> 📏 **Правило:** започват <ins>задължително</ins> с **буква** или **долна черта** (`_`), а след това могат да съдържат букви, цифри и `_`.

| ✅ Правилно | ❌ Грешно |
| :--------- | :------- |
| `min` | `1236ds` *(започва с цифра)* |
| `sum` | `кутия` *(кирилица)* |
| `maxNum` | `smetni obikolka` *(интервал)* |
| `box0` | `nameri.chislo` *(точка)* |
| `calculate_area` | |

### 🔐 Запазени думи (Keywords)

Думи, които ***не могат да се променят*** и означават конкретна конструкция на езика.

<kbd>for</kbd> <kbd>while</kbd> <kbd>class</kbd> <kbd>static</kbd> <kbd>virtual</kbd> <kbd>struct</kbd> <kbd>break</kbd> <kbd>int</kbd> <kbd>const</kbd> *…и т.н.*

### 📝 Statements (оператори / инструкции)

Това са ***инструкциите*** към програмата.

> ❗ Всяка инструкция <ins>**винаги**</ins> завършва с `;`

### 📦 Variables (променливи)

Място, в което се съхранява стойност, която ***може да се променя*** по време на изпълнение на програмата.

| Характеристика | Описание |
| :------------- | :------- |
| 📍 **Място в паметта** | клетка в стека (Stack) |
| 🏷️ **Име** | идентификатор |
| 🧩 **Тип** | какви стойности може да пази |
| 💎 **Стойност** | текущото съдържание |

### 🔒 Constants (константи)

Подобни са на променливите, но ***не могат да се променят*** след създаването си.

### 💬 Коментари

Части от кода, които ***не се компилират***. Използват се, за да:

- обясним програмата;
- поясним сложен код;
- изключим временно част от кода.

## 📦 Типове данни в езика C++

Всяка променлива има ***тип***, който определя:

1. 🎯 множеството от **допустими стойности**;
2. ⚙️ **операциите**, които могат да се извършват с нея.

| Вид | Описание |
| :-- | :------- |
| 🏗️ **Вградени** | дефинирани и поддържани от самия език |
| 🧪 **Абстрактни** | дефинирани от програмиста чрез класове и структури *(ще ги учите следващия семестър по ООП)* |

Вградените типове се делят на ***скаларни*** (една компонента) и ***съставни*** (редица от елементи):

| 🔹 Скаларни | 🔸 Съставни |
| :---------- | :---------- |
| Булев | Масив |
| Цял | Символен низ |
| Реален | Вектор |
| Символен | Указател |

> 💡 ***Примитивните*** (*primitive*) типове са в основата на езика. Те представят символ, цяло число, дробно число и др. От тях се изграждат по-сложните типове *(например текстът се състои от много символи)*.

### 1️⃣ Числа

Числата биват **цели** *(23, -76, 0)* и **дробни/реални** *(76.69, 3.14, -77.99)*. Размерът в паметта определя ***границите*** на всеки тип.

#### 🔢 Целочислени типове

| Тип | Размер | Диапазон |
| :-: | :----: | :------- |
| `short` | 16 бита (2 байта) | от **-32 768** до **32 767** |
| `int` | 32 бита (4 байта) | от **-2 147 483 648** до **2 147 483 647** |
| `long long` | 64 бита (8 байта) | от **-2<sup>63</sup>** до **2<sup>63</sup> − 1** |

> ⚠️ **Важно:** стандартът на C++ <ins>**не гарантира**</ins>, че `int` е 4 байта. Същото важи за `long`: той е поне 32 бита и на Windows обикновено е 4 байта, а не 8.

#### 🌊 Дробни (реални) типове

| Тип | Размер | Диапазон | Точност |
| :-: | :----: | :------- | :------ |
| `float` | 32 бита (4 байта) | от **-3.4E+38** до **3.4E+38** | единична |
| `double` | 64 бита (8 байта) | от **-1.7E+308** до **1.7E+308** | двойна *(IEEE 754)* |

### 2️⃣ Символи

Типът `char` пази ***знаци***: букви, цифри, аритметични оператори и др.

- `char` → **8 бита (1 байт)**, т.е. 256 възможни стойности *(кодове от ASCII таблицата)*

```cpp
char el = 'a';   // в паметта се пази числото 97
```

> 🕵️ ***Знаците всъщност са числа под прикритие!***

### 3️⃣ Булев (логически) тип

Използва се, когато има ***само две*** възможни стойности: истина или лъжа.

- `bool` → **8 бита (1 байт)** → `true` / `false` *(`1` / `0`)*

> 💡 Изключително полезен е в условия и цикли: `if`, `else if`, `while`.

## ✍️ Команда за присвояване

> 📐 **Формат:** `<променлива> = <израз>;`

```cpp
sum = 8 + 3 * 5;
x = y = z = 69;
```

> ❗ **Правило:** ***първо*** се изчислява изразът отдясно и ***чак след това*** стойността се записва в променливата отляво.
> Верижното присвояване се изпълнява <ins>**от дясно наляво**</ins>.

### 📦 Създаване на променливи и константи

Представете си променливите като ***кутии с различна форма***:

| 📦 Кутията | 💻 В C++ |
| :--------- | :------- |
| **Формата** на кутията | типът (*type*) |
| **Съдържанието** | стойността (*value*) |
| **Цялата кутия** | променливата (*variable*), защото съдържанието може да се сменя |
| **Етикетът** с уникално име | идентификаторът (*identifier*) |

> ⛔ **Не можем** да ползваме запазени думи като имена на променливи!
> ~~`char char = 'a';`~~

#### 🧪 Примери за декларации

```cpp
short smallNum = 19;     // Променлива от тип short
int num = 256;           // Променлива от тип int
long long bigNum = 9999; // Променлива от тип long long

float fpNum = 2.34f;     // Променлива от тип float
double bigFpNum = 9.99;  // Променлива от тип double

char dollar = '$';       // Променлива от тип char
bool canSing = false;    // Променлива от тип bool

const double pi = 3.14;  // Константа от тип double (стойността ѝ е защитена от промяна)
```

## ➗ Основни операции

За примерите по-долу:

```cpp
int x = 3;
int y = 5;
```

> 💡 Всеки тип поддържа ***свои*** операции. Например `%` работи <ins>**само с цели числа**</ins>.

### 1️⃣ Аритметични операции

> ⚠️ Резултатът зависи от ***типовете*** в израза. При деление на два `int` дробната част се ***отрязва***.

| Оператор | Действие | Пример |
| :------: | :------- | :----- |
| `+` | събира двата операнда | `x + y` → **`8`** |
| `-` | изважда десния операнд от левия | `y - x` → **`2`** |
| `*` | умножава двата операнда | `x * y` → **`15`** |
| `/` | дели първия на втория *(целочислено при `int`)* | `y / x` → **`1`** |
| `%` | остатък при деление | `y % x` → **`2`** |
| `++` | увеличава с 1 | `x++` → `x` става **`4`** |
| `--` | намалява с 1 | `y--` → `y` става **`4`** |

#### 🔁 Префиксна vs. постфиксна форма

| Форма | Какво прави |
| :---- | :---------- |
| **Постфиксна** `x++` | ***първо*** връща старата стойност, ***после*** увеличава |
| **Префиксна** `++x` | ***първо*** увеличава, ***после*** връща новата стойност |

```cpp
int x = 5;
std::cout << (x++) + 5; // използва старото x = 5 → 5 + 5 = 10
std::cout << x;         // вече x = 6
```

### 2️⃣ Оператори за сравнение

> 🎯 Резултатът ***винаги*** е `bool` (`true` или `false`).

| Оператор | Връща `true`, ако… | Пример |
| :------: | :----------------- | :----- |
| `==` | `x` и `y` са **равни** | `x == y` → `false` |
| `!=` | `x` и `y` са **различни** | `x != y` → `true` |
| `>` | `x` е **строго по-голямо** от `y` | `x > y` → `false` |
| `<` | `x` е **строго по-малко** от `y` | `x < y` → `true` |
| `>=` | `x` е **по-голямо или равно** на `y` | `x >= y` → `false` |
| `<=` | `x` е **по-малко или равно** на `y` | `x <= y` → `true` |

### 3️⃣ Логически оператори

> 🎯 Резултатът отново е `bool`.

```cpp
bool x = true;   // същото като: bool x = 1;
bool y = false;  // същото като: bool y = 0;
```

| Оператор | Действие | Пример |
| :------: | :------- | :----- |
| `&&` *(and)* | `true` ***само ако и двата*** са `true` | `x && y` → `false` |
| `\|\|` *(or)* | `true`, ако ***поне един*** е `true` | `x \|\| y` → `true` |
| `!` *(not)* | ***обръща*** стойността | `!x` → `false`, `!y` → `true` |

#### ⚡ Късо съединение (short-circuit evaluation)

> - При `&&`: ако първият операнд е `false`, резултатът е `false` и десният операнд <ins>**не се изчислява**</ins>.
> - При `||`: ако първият операнд е `true`, резултатът е `true` и десният операнд <ins>**не се изчислява**</ins>.

## ⌨️ Вход/изход от конзолата

За да работим с конзолата, включваме библиотеката:

```cpp
#include <iostream>
```

> 🚫 **Добра практика:** ***не*** използвайте `using namespace std;`. Пишете `std::`, за да избегнете конфликти между имена.

<table>
<tr><th>📥 Въвеждане: <code>std::cin</code></th><th>📤 Извеждане: <code>std::cout</code></th></tr>
<tr>
<td>

Изчаква потребителя да въведе стойност и я записва в променлива.

```cpp
std::cin >> n;

std::cin >> a >> b;
```

</td>
<td>

Отпечатва стойност или текст в конзолата.

```cpp
std::cout << n;

std::cout << "Test";
```

</td>
</tr>
</table>

### ↩️ Нов ред

> 🏎️ Предпочитайте `"\n"` пред `std::endl`. `std::endl` ***принудително изпразва буфера*** и затова е по-бавен.

```cpp
std::cout << "Hello" << "\n" << "there!";
```

## 🏁 Начало на една C++ програма

### 🦴 Основен скелет

```cpp
#include <iostream>

// using namespace std; // Не се препоръчва

int main()
{
    // Кодът на програмата

    return 0;
}
```

### 🎬 Функцията `main()`

> 🚪 Всяка C++ програма ***започва изпълнението си*** от `main()`.

```cpp
int main() // Началната (главна) функция на програмата
{
    std::cout << "Hello World\n"; // Извежда текст и преминава на нов ред

    return 0; // Код 0 към ОС → програмата е приключила успешно
}
```
